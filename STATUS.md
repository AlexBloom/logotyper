# Status

Updated: 2026-11-16, America/New_York.

Product: **mark this word**, a live typography workbench. Repository and legacy CLI/skill names remain wordmark-generator. Development is on dev; main is protected. No production website is deployed.

Implemented: stacked outlined architect identity; source/category/tag filters; system fonts and multiple directories/uploads; Google 20-family starter; deterministic shuffle/reset and related-font ranking; 24-card pages with four concurrent near-viewport font loads; live tracking/leading and four layouts; independent collection rounds and ten-step variations; per-word mixed fonts, element dragging, rotation, outlines, individual letter editing, duplication/removal and typed symbols; undo/redo, browser autosave and project files; deferred native SVG/PNG exports; Figma copy/download and local Illustrator open actions; optional agent brief/patch handoff. CLI/HTTP/MCP expose live catalog, composition and iteration as well as compatible batch generation. Adobe/premium setup panels disclose that no licensed provider account is connected.

Validation: JavaScript syntax checks, both Swift builds and all eight integration/model tests pass locally. Tests cover all original quantities through 250; exports, uploads, origin checks and MCP discovery; stable shuffle, similarity, mixed-font layout, positioned variations, invalid suggestions; catalog, TTC face extraction and outlined composition through HTTP. Portable skill frontmatter validates and its installed launcher exposes the v2 commands. Desktop and 390px mobile browser checks cover source/category browsing, architect-directory discovery, collection variations, outline/letter editing and export controls. A native outlined Tekton PNG was visually inspected. Google starter download returned an exportable TTF. Actual insertion into a Figma document and launching Illustrator were not exercised; handoff controls and vector outputs were verified.

Observed local indexing: 132 compatible system families in about 0.5 seconds; the selected architect directory yielded 21 families. These are this Mac's inventory/timing, not portable performance guarantees. Large directories must finish native discovery before their initial results appear; no progressive persistent catalog index is implemented. Metadata reads are bounded rather than retaining every source font in memory.

Preview: http://127.0.0.1:9010 for this build; npm start defaults to port 9000. Runtime files are ignored under .wordmark/ and .cache/. The earlier GUI remains at /batch.html. The existing installed wordmark-generator skill has been updated with the new runtime; its prior installation was backed up locally.

Limits: macOS native rendering; one discovered face per family; heuristic categories/similarity; 20-family Google starter rather than full catalog; paid-provider adapters need licensing/onboarding; no built-in model account, remote document editing, public phone tunnel or production deployment. Project JSON references local sources. Users are responsible for font licensing.
