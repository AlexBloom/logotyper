Updated: 2026-11-19, America/New_York.

Implemented: supplied logotyper SVG identity; source/category/tag filters; system fonts and multiple directories/uploads; Google 20-family starter; deterministic shuffle/reset and related-font ranking; 24-card pages with four concurrent near-viewport font loads; live tracking/leading and five layouts; independent collection rounds and ten-step variations; per-word mixed fonts, element dragging, rotation, outlines, individual letter editing, duplication/removal and typed symbols; undo/redo, browser autosave and project files; deferred native SVG/PNG exports; Figma copy/download and local Illustrator open actions; optional agent brief/patch handoff. Metadata reads are bounded rather than retaining every source font in memory.
